# 新 BC 独立训练曲线

数据来自 ../../all_epochs.csv 的 D_新BC独立，共 78 条记录。沿用 2026-09-12 的历史快照，没有重新连接 HPC 或补测。

- independent_bc_overview：三模型 × 三指标总图。
- qwen_*_bc_curves：每个模型的单独横向图。
- PNG 为 300 dpi；SVG 保留可编辑文字；PDF 为矢量导出。
- 同色同符号始终代表同一个种子，三种子不平均；曲线不平滑、不插值。
- loss 使用对数纵轴，便于观察后几轮的细小变化。吞吐和 Static 百分比使用线性轴。
- 14B E8 仅绘制 loss；吞吐缺失用灰色区域注明。
- 吞吐计入原验证中的网络决策耗时；每个条件的三次重复先取中位数，再对25个条件取几何平均。
- Static 参考来自同阶段、同条件的基线，不是新的测量。
- 全部结果是模拟时序/调度回放，不代表真实 Qwen 推理吞吐。

数据核对：1.8B 24条、7B 30条、14B 24条；吞吐缺失仅为14B E8的3个种子。
