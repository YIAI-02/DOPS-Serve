# BC 对教师安排的学习差距：2026-09-13 诊断

## 结论与范围

教师在本轮 24 个验证任务上均快于 PD；独立 7B 的一个可复现案例显示，prefill 与第一次 decode 的模仿不足会改变后续现场，继而造成长时间的低效设备安排。只替换这两份开头安排、不改 E10 参数，就将该案例总耗时从 2.312556 秒降至 0.786811 秒。

本次只使用已完成的 BC 检查点和验证集，未训练、未读取 test、未恢复监控。所有吞吐统一排除 BC、PD 和教师的决策耗时，表示 DOPS fast 模拟安排的执行质量。节点级与干预结论只针对 case 068，不能直接外推全部模型。

## 哪些安排不同

在 E10 的 prefill 中，169/616 个学习节点与教师不同，这 169 个节点都是教师选择 PIM、BC 选择 NPU。例如：

|阶段/节点|教师|E10|
|---|---|---|
|prefill / L0_Q_s1|PIM0|NPU|
|prefill / L0_FFN_W3_s0|PIM0|NPU|
|prefill / L0_FFN_W1_s1|PIM1|NPU|
|prefill / L0_FFN_W2_s1|PIM1|NPU|
|decode t=64 / L0_FFN_W3_s0|PIM0|NPU|
|decode t=64 / L0_FFN_W3_s1|PIM1|NPU|
|decode t=64 / L0_FFN_W2_s0|PIM0|NPU|
|decode t=64 / L0_FFN_W2_s1|PIM1|NPU|

E10 在 decode t=64 有 520/616 个学习节点与教师不同，其中 512 个是教师选择 PIM、BC 改为 NPU。不同设备不必然意味着性能差：E8 也有大量 PIM0/PIM1 互换，执行仍接近教师。因此最终依据执行时间和干预结果判断，不能把动作不一致率直接当成性能损失。

## 为什么平均 loss 没有揭示完整问题

本轮是单赢家条件 NLL，不是旧版多候选加权 BC。完整答案被拆成每个决策现场的一份计划；每个计划先平均学习节点 NLL，再对一个任务的所有计划取平均。

1. **开头安排权重太小。** `static_bc.py:325` 对每份计划赋权 `1/len(task)`。decode=128 时 prefill 只占 1/66，decode=1024 时只占 1/514。四种 decode 长度的任务等权后，prefill 在汇总目标中的份额约 0.7166%。首次 decode 也只有同样小的一份。当前权重并未区分某次决定是否会改变整个后续执行。
2. **教师现场与自主现场不同。** 训练样本沿教师轨迹产生；条件 NLL 的同一计划前缀也使用教师动作。验证则输入 BC 实际形成的 prefill/上一份 decode 设备映射、缓存和设备时间线。前几次选择偏离，后面接收到的输入就变了。
3. **多数稳定 decode 掩盖少数开头难点。** 在 case 068，E10 的 prefill 条件 NLL=1.83584，但 65 个 decode 平均为 0.02831，整任务平均降到 0.05570。E10 的所有验证任务平均 NLL 为 0.02132，这不代表每个阶段、每个任务都学好。

|E10 对比方式|学习节点设备一致率|含义|
|---|---:|---|
|教师现场，计划内也给教师前缀|98.96%|接近训练 loss 的输入条件|
|教师现场，计划内自己逐节点生成|98.62%|只引入计划内自主生成|
|从头自主执行，现场也由自己形成|16.85%|实际验证条件|

只看 decode：在教师现场自主生成的一致率为 99.02%，完整自主执行后为 16.00%。但这个平均也掩盖了开头：在正确教师现场，首次 decode 已有 270/616 个学习节点不同，而 t=64 仅有 1/616 不同。说明稳定阶段答案较容易，启动阶段仍是明显薄弱点。

E8 到 E10 的训练 NLL 从 0.007623 升至 0.009169，验证 NLL 从 0.019303 升至 0.021320；这两轮不是 loss 持续下降的例子。总体 loss 较小与吞吐差的脱节，仍由上述按阶段分解与自主执行检查直接呈现。

## 建议的最小后续验证

- 保留现有检查点与结果；7B E8 是当前验证吞吐最佳的一轮，不将 E10 自动当最佳。
- 优先对 prefill、启动 decode、稳定 decode 分组计 loss，调整各组训练权重；同时报告各阶段匹配和完整任务吞吐。是否能通过重新训练改善，尚需对照验证，当前没有做该训练。
- 补充 BC 自己执行后产生的现场，由教师在同一现场重新给安排；不能把旧教师现场的答案直接当成新现场的最优答案。
- 吞吐继续通过完整自主回放验收。当前诊断尚未证明加深网络能够解决问题。
