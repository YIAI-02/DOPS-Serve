# BC、PPO 与基线比较，以及继续训练一轮的结果

**全部实验成功结束；PPO 的改善有模型和种子差异，目前没有学习策略达到本轮 SLO 要求。**

截至 2026-09-06 12:59:21（北京时间）核对：最后汇总作业于 12:49:55 完成。165 个条件、90 组前后配对、3 个续训 checkpoint/summary 均齐全。每个条件完成同一条验证 trace 的 1000 个请求，输出均为 21648 tokens；共 165000 次请求回放，不是 165000 条独立验证样本。169 份作业日志未匹配到 Traceback、OOM、Slurm 错误等异常；相关作业退出码全部为 0。续训曲线未发现非有限数值。

## 1. 先读结论

- 原 PPO 相比 BC：1.8B、7B 的配对平均吞吐提高、p99 降低；14B 的平均吞吐下降、p99 升高。不能把小模型的进步推广到全部模型。
- 再训练一轮：种子 27 在 1.8B/7B 明显改善，种子 17 在两者均退步，种子 7 变化很小；14B 基本没有改善。不同种子相当于从不同随机起点训练的三名学生，不是三套独立测试题。
- 五档负载中，BC、原 PPO、续训 PPO 和本轮固定顺序 Bifocal 均没有达到“E2E 违约率 ≤ 1%”。Static 在三个模型的 0.5×R 档位达标。未达标表示没有找到符合门槛的测试档位，不表示吞吐为零。
- 当前证据不支持直接扩大 PPO 训练量并预期稳定变好。建议先定位 14B 退步和种子差异，再决定是否延长训练；本次没有追加新实验。

## 6. 结果适用范围与后续判断

- 本轮使用固定的 burstgpt_val_000000，共 1000 请求；正式 test 未使用。三个模型、五档到达率、三种子均已纳入。
- 范围是 1 NPU + 2 PIM、FP16 decoder DAG 的时序/调度回放，没有执行真实 tensor 推理，不能据此宣称真实模型推理加速。
- Bifocal 使用当前后端评分，并约束为固定拓扑顺序、每节点固定 PIM；当前 gamma=0，属于受共同动作空间约束的适配版本。结果不能外推为原始 Bifocal 所有配置的结论。
- 继续训练的改善在种子间不一致，且 14B 没有恢复。后续应先检查共享策略在各模型上的动作分配与奖励分项，解释退步；若确认目标与动作合理，再增加训练 trace 覆盖并复测。此处是基于本轮证据的下一步建议，尚未运行这些诊断或追加训练。
