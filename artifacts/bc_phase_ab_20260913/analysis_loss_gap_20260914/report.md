# BC loss 与完整吞吐背离：固定检查点诊断

2026-09-14，计算节点作业 14878036（bc26-loss-probe）正常完成，ExitCode 0:0，用时 1 分 30 秒。未更新任何模型参数；未运行 PPO 或 test；监控保持暂停。

## 结论

loss 下降表示在给定样本、教师状态和教师前序动作的条件下，教师动作的加权几何平均概率提高。它不等于选对节点的比例提高，也不保证自主执行后遇到的状态仍能处理好。

本次同时发现：B 的训练目标在训练集变好、验证集变差；一些关键启动安排持续错误；自主执行状态偏离教师状态后，后续安排明显变化。阶段加权让 B 学到了一部分有效的后续决策，但没有解决开头的错误。

## 2. B 的实际验证目标变差

|指标|E8|B E18|解释|
|---|---:|---:|---|
|实际训练目标：三阶段等权 NLL|0.116243|0.051280|训练集改善|
|对应验证目标：三阶段等权 NLL|0.448695|0.506336|验证集变差|
|公共原口径验证 NLL|0.019303|0.019132|仅小幅改善，权重不同|

之前主表保留公共原口径 NLL 便于 A/B 对照。它不是 B 实际优化目标的同一加权方式，不能用这个数判断 B 的三阶段目标是否在验证集改善。这是过拟合/泛化不足的直接表现，但没有确定更深网络就能解决。

## 3. 相同现场下，NLL 下降也可能选对更少

以下固定 case 68、首次 decode（t=0）、教师状态、教师前序动作；只换模型参数。

|检查点|条件 NLL|节点选择与教师一致率|
|---|---:|---:|
|E8|0.656340|90.10%|
|A18|0.733381|82.47%|
|B18|0.534524|86.20%|

B 的 NLL 比 E8 更低，但 argmax 动作一致率更低。原因是 NLL 给“教师动作的概率”评分，而一致率只看概率最大的是谁。不同节点的信心变化还会互相抵消。

另一个实际例子：case 68 prefill 的 node_index=4，教师选择 PIM0；A 将 PIM0 概率从 0.7067% 提高到 1.1418%，该节点 NLL 从 4.9524 降至 4.4726，但 NPU 仍有 97.7868% 的概率，因此实际设备选择仍错误。

## 4. 同样错误的开头，后面的状态却很重要

case 68 的 prefill 有 616 个学习节点；E8、A E18、B E18 都是相同的 169 个节点偏离教师。这 169 个节点应去 PIM，却选择 NPU。八任务汇总的 prefill 一致率 86.28% 掩盖了这一形状只有 72.56%。

所有 8 个验证任务从 E8 到两路 E18 的 prefill 时间都完全不变；新增耗时全部在 decode。因此不能把此次变慢简单解释为“prefill 本身越来越慢”。

B E18 在 case 68、t=64 的条件比较：

|输入现场|同一安排内的前序动作|条件 NLL|三设备一致率|仅区分 NPU/PIM 的一致率|
|---|---|---:|---:|---:|
|teacher|teacher|0.015339|99.84%|100.00%|
|teacher|own|0.015339|99.84%|100.00%|
|own|teacher|3.528423|53.90%|86.20%|
|own|own|3.813753|53.90%|86.20%|

此处 teacher 现场来自教师完整轨迹，own 现场来自模型自己的完整执行。保持教师现场时，即使当前安排内自行选择前序节点，仍达到 99.84% 一致率；换成自主执行后的现场，即使给出当前安排的前序教师答案，一致率也降到 53.90%。因此在该现场，跨阶段状态差异比当前安排内的前序误差更突出。
自主状态下有 79/616 个节点由教师 PIM 改成 NPU；因此差异不全是 PIM0/PIM1 对调。但动作不同本身不等于更慢，性能判断仍依据完整回放。

## 5. 因果干预：只替换开头两份安排

同一 case 68，共 66 份安排。替换 prefill 与首次 decode 后，余下 64 份仍由对应模型自己生成；模型参数不变。教师完整时间为 0.712729 秒。

|检查点|完全自主，秒|仅教师 prefill，秒|教师 prefill + 首次 decode，秒|两步替换后吞吐/教师|
|---|---:|---:|---:|---:|
|E8|0.821176|0.779232|0.787046|90.56%|
|A18|1.016137|1.384947|0.784934|90.80%|
|B18|1.005820|0.913975|0.737615|96.63%|

B 的两步替换消除了相对教师额外耗时的 91.51%，达到教师吞吐的 96.63%。这支持“开头错误和后续状态偏移是该任务主要瓶颈”。它证明 B 已学到部分有效的后续决策，不证明该干预在所有形状都有效。
单独替换 prefill 对 A 反而变慢，说明首次 decode 的选择也必须检查；不能假定只纠正一个阶段就一定改善整体。

## 6. 哪类任务退步

|分支|batch=1、prompt=512 四任务吞吐变化|batch=8、prompt=2048 四任务吞吐变化|
|---|---:|---:|
|A E18 相对 E8|-36.09%|-11.82%|
|B E18 相对 E8|-34.36%|+0.97%|

每组使用四个 decode 长度的总 token / 总模拟时间，不平均任务吞吐。这说明 B 的改善集中在较大 batch，而平均数掩盖了小 batch 的明显退步。

## 下一步建议

- 保留 E8、A E18、B E18 供对照，不直接继续堆 epoch。
- 从训练任务补充或挖掘 prefill/首次 decode 的困难现场，检查完整安排是否学对；不能把本次验证 case 68 直接加入训练后仍沿用它宣称验证改善。
- 若增加自主状态训练，应在模型实际到达的状态上重新求教师安排，再作为新 BC 样本；不能无条件把旧教师轨迹的动作贴到不同状态上。
- 继续同时看实际训练目标、对应验证目标、关键阶段完整动作，以及自主完整吞吐。下一轮训练需用户确认，本次没有训练或修改网络。
