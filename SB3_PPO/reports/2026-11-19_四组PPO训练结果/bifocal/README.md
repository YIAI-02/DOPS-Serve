# 196 工况 Bifocal 参数搜索结果

全部 **3,136** 个组合已完成，**447** 个获选计划通过独立逐 token 回放核对。搜索于 2026-11-19 08:26:02 结束，回放于 09:06:34 完成。完整结果与计划共 3,160 个文件已取回并逐字节核对。

## 1 实验设置

Qwen 1.8B，28 层，FP16，1 NPU + 2 PIM。prefill 和 decode 均取 64、256、512、1024、2048、4096、8192 token，batch 为 1、4、8、16，共 196 种合成工况。复用既有 16 组候选，全部固定 seed 0、PYTHONHASHSEED=0。每批冷启动，逐个真实 decode token 执行，放置刷新间隔与本轮 PPO 一致，为 `min(256, ceil(decode_len/16))`。

Bifocal 的节点顺序和逐节点放置直接由其搜索生成，沿用跨层的细粒度计划；A/B 为既有的层间共享放置策略。二者使用相同的执行耗时内核。Bifocal 远期评分仍使用候选的固定复用窗口，未把真实剩余输出长度送入评分。

共用参数按 196 工况的平均归一化耗时选取：先逐工况除以同工况冷启动全 NPU 批次耗时，再等权平均。另列按平均绝对毫秒数选共用参数的结果，以及每个工况从 16 组候选中单独取最快结果的参考值。以下均为解析模拟结果，未使用 BurstGPT；仅说明现有候选集内的结果。

## 2 最好共用参数

## 6 数据与验收

搜索由四个独立 64 CPU 分片并行执行，每片 784 个组合。全部 3,136 项唯一覆盖 196 工况 × 16 候选。独立回放覆盖默认共用参数（512）、按绝对耗时选出的共用参数及逐工况获选计划，去重后共 447 个；完整批次耗时差不超过 1e−9 ms。并列的 1024 候选在全部工况的原生搜索耗时与 512 完全相同。原始实验保留所有搜索计划；本目录提供两个代表工况的原生生成计划。每个工况调用前将 `bifocal_search.REFRESH_TOKENS` 设为 `refresh_stride(decode_len, 256)`，计划由 `run_trial` 生成，使用 `verify_replay` 独立核对。

四组共 12 个 PPO Final 均已验收，已冻结 A / seed 1 并启动 BurstGPT，最终泛化尚未完成。本次 Bifocal 参数搜索单独计量，不增加 PPO 环境步预算。
